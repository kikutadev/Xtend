# ADR 0007: 全画面でWebKit標準の履歴ジェスチャーを使う

- 決定日: 2026-11-04
- 状態: Accepted
- 関連: [ADR 0003](0003-built-in-x-navigation.md)

## 背景

ホームだけ戻るジェスチャーを無効化し、右端に専用の進む処理を足したが、画面ごとに異なる操作と実装の重複を生んだ。

## 決定

- 全ページの左右端は原則としてWebKit標準の履歴操作（戻る・進む）が担当し、専用の進むジェスチャーは廃止する。
- Xホームのメニューは、WebKitに戻る履歴がない場合にのみ左端スワイプを扱う。戻る履歴がある場合は戻るを優先する。メニューはプロフィールアイコンからも開ける。
- 履歴の有無はWKWebViewのcanGoBackを正本とし、KVOで既存のXスワイプスクリプトに通知する。XのURLやSPAページ種別で閲覧履歴の有効・無効を切り替えない。
- 画面中央のタイムライン切り替えと開いているメニューの閉じる操作は既存のX操作を維持する。

## 採らない方法

ホーム用の進むジェスチャー追加、ページ種別ごとのWebKit有効化、JavaScript側でブラウザ履歴を独自管理する方式は、機能重複・競合・保守負担のため採らない。
