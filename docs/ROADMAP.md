## 今後追加する拡張機能・操作改善

### 新規 Chrome 拡張機能：タイムラインのアカウント許可リストフィルター

**状態：独立WXT拡張機能として実装・ChromeのモックE2Eまで完了（`../x-timeline-filter/`）。実際のXでのフィルター操作、実Xリストからの取り込み、Xtend実機への対応は未検証・未実装。**

**目的：** 利用者が端末内に登録したアカウントの投稿だけを X のタイムラインに表示し、それ以外をクライアント側で非表示にする。X のフォロー・ミュート・ブロック・リスト設定そのものは変更しない。

**必須機能（第1段階）**

1. WXT / Manifest V3 ベースの独立した Chrome 拡張機能を作成する。PC の Chrome でまず動作させ、Xtend での利用は別途互換性を検証する。
2. 許可アカウントを **拡張機能専用の `chrome.storage.local`** に永続保存する。X ページの `window.localStorage` に保存しない。アカウントを追加・削除・一覧確認できる。
3. X が通常どおり取得し描画した投稿を、Content Script が DOM 上で判別し、**許可リスト外のアカウントの投稿だけを非表示**にする。通信遮断、取得リクエストの書き換え、X のサーバー側フィルター操作は行わない。
4. ホームの「おすすめ」「フォロー中」を最初の対象にする。追加読み込み、無限スクロール、画面内の仮想化・再描画、タブ切り替え後もフィルターが持続するようにする。通常の投稿の著者を判定し、再投稿では再投稿者でなく **元投稿の著者** を基準にする。引用投稿や複数著者の表示は実画面で挙動を確認し、対象外投稿が露出しない条件を詰める。
5. 拡張機能の設定 UI でフィルターの ON/OFF と、許可アカウントをまとめた **表示グループ（プリセット）の切り替え** を提供する。切り替え時はページ再読み込みなしで表示を再評価する。
6. 通常の閲覧中は、判定・表示制御のための X API 呼び出し、認証情報取得、外部サーバー送信を行わない。不要な権限を要求しない。**「X に絶対検知されない」ことは保証しない** が、フィルタリングを X への追加リクエストやアカウント操作として送らない設計にする。

**追加機能（第2段階、技術検証後）：「X のリスト」から許可アカウントを取り込む**

**実装状況（2026-10-24）：** 表示済みのメンバーをDOMから読み取り、スクロール中に読み込んだ分をタブ内に蓄積してグループに追加する機能を実装。全件自動取得・自動同期は行わない。実Xのリスト画面での取り込みは未検証。

- 利用者が X 上で閲覧できるリストのメンバー情報を元に、許可グループを作成・更新できるようにする。取り込み先を新規グループ／既存グループから選べるようにする。
- 第一候補は、利用者が通常操作で開いたリストの **メンバー画面に表示された情報を読み取り**、端末内へ保存する方式。リスト閲覧に伴う X 本来の通信は発生するが、取り込み専用の非公開 API 呼び出しや大量の自動アクセスを前提にしない。
- X のメンバー画面が遅延読み込み・ページ分割される場合は、**取得件数と未取得の可能性**を明示する。全件取り込みが実現できないのに「同期完了」とは表示しない。
- リストへの加入・離脱や X 側の設定を変更する機能ではなく、あくまでローカルへの取り込み。取り込んだグループの切り替えは X に通知しない。自動同期の導入は別途判断する。
- リスト取り込みが DOM 制約等で安定しない場合も、手動追加とローカルグループ切り替えは独立して利用可能にする。

**実装前に確認すること**

- 実際の X の DOM と SPA 遷移、ポスト・再投稿・引用の著者識別方法、動的 DOM 監視の性能。X 側の変更で誤非表示が起こった場合に、すぐ OFF に戻せること。
- WXT の Content Script と `chrome.storage.local` の利用が、PC Chrome と Xtend の限定的 Chrome API 実装の双方で成立するか。Xtend は現状インストール対象を限定しているため、**この新拡張機能を認識・インストール・起動する Xtend 側の対応も別タスク**とする（Phase 2 の「汎用拡張機能対応」には含めない）。
- X のリスト画面でメンバーが全件取得可能か、非公開リストへのアクセス権限の扱い、メンバー数が多い場合の欠落や重複。

**完了条件**

- Chrome で登録済みアカウントの通常投稿は表示され、未登録アカウントの通常投稿は表示されない。無限スクロール・タブ移動・新着更新・グループ切り替え後も動作し、表示設定は再起動後も保持される。
- フィルター ON/OFF やグループ切り替えで、X 側への追加のフィルター通信やフォロー・ミュート・ブロック操作が発生しないことを通信ログ等で検証する。通常の X 閲覧通信そのものは止めない。
- リスト取り込みを実装した場合は、画面上で確認可能なメンバーと取り込み結果を照合し、未取得分を検出・表示する。拡張機能と Xtend 本体の動作検証結果は分けて記録する。
